FinSight — AWS Cloud Architecture Overview
Zero-NAT Enterprise Cloud Topology • Region: AWS Mumbai (ap-south-1)
Production Ready
🌐 1. Edge & Delivery
Amazon CloudFront CDN
Global content delivery network caching React static assets with HTTPS TLS 1.3 encryption.
AWS WAFv2 Security
Protects against web exploits, OWASP Top 10 vulnerabilities, and applies strict rate limiting.
Amazon S3 (SPA) Storage
Hosts compiled Vite React single-page frontend assets with Origin Access Control (OAC).
⚡ 2. Compute & API
Application Load Balancer ALB
Distributes incoming REST API traffic (/api/*) evenly across private container tasks.
AWS ECS Fargate Serverless
Runs containerized Node.js 20 backend microservices with automatic scaling & zero server maintenance.
AWS VPC Endpoints Zero-NAT
Private endpoints connecting ECS to AWS services without costly NAT gateways (~70% cost savings).
🧠 3. Data & AI Services
Amazon DynamoDB Database
Single-table NoSQL store for ultra-fast user sessions, audit logs, and recurring templates.
Amazon Textract AI OCR
AnalyzeExpense AI engine extracts itemized line items, totals, and taxes from receipt photos.
Amazon Bedrock GenAI
Titan Express LLM normalizes noisy merchant names and categorizes natural language expenses.
Amazon SES & SQS Async
Asynchronous event queues and automated email delivery for bill alerts & split invites.
